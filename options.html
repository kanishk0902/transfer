Claude Chat Transfer — Options

Handoff brief

Privacy: the key is stored in chrome.storage.local on this machine only — it is never synced and never sent anywhere except api.anthropic.com. Choosing this option means the full transcript of each chat you save is sent to the Anthropic API under your own key and billed to your account. The default "ask the open chat" option sends nothing outside claude.ai.

Google Drive sync

Both scopes are limited to files this extension creates. The extension can never read the rest of your Drive. Chat content goes only to your own Drive account. Drive sync needs a one-time Google Cloud setup — see the README.

Debug

Debug mode is the only situation in which chat content is written to the console, and it stays on your machine. Leave it off unless you are reporting broken extraction.
